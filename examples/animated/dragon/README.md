# Animated flying dragon

Original model and animations by MattBas.
Source: https://opengameart.org/content/simple-3d-dragon-model
Downloaded 2026-10-11 from https://opengameart.org/sites/default/files/dragon.tar_1.gz

Original model, texture and licence file are unchanged. Credit MattBas when
redistributing; adaptations of the asset must retain the same licence.

Choose dragon.glb in WCM → Object inside cube → OBJ/GLB model or folder path.
Enable Play model animation. Animation clip indices:

- 0: Flying-loop
- 1: Idle-loop
- 2: Run-loop
- 3: Walk-loop

Start with Object size 0.8 and Animation speed 1. Keep glax.png beside the GLB.
Adjust Object rotation/Flip object vertically if needed for your preferred view.
