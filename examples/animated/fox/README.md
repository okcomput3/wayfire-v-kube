# Animated textured Fox

Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
Downloaded 2026-10-11. Original GLB is unchanged; licence details in LICENSE.md.

Credits:
- Model: PixelMannen (CC0).
- Rigging and animation: tomkranis (CC BY 4.0).
- glTF conversion: AsoboStudio and scurest (CC BY 4.0).

Choose Fox.glb in WCM's OBJ/GLB model path and enable Play model animation.
Clip 0 = Survey, 1 = Walk, 2 = Run. Speed 1 = normal playback.
The colour texture is embedded, so no separate MTL/images are needed.
Try model size 0.85, Object rotation 90 degrees for a side view, and disable
Flip object vertically initially. Reduce desktop opacity to see it clearly.
This is a textured animated model scene, not a video/animated-image texture.
