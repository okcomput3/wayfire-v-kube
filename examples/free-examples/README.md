# Free cube OBJ examples

Downloaded from Kenney on 2026-10-11. All models are CC0; original licences are included.

- Food Kit: https://kenney.nl/assets/food-kit
- Space Kit: https://kenney.nl/assets/space-kit

Choose any `.obj` in WCM → Object inside cube → OBJ model path.
Keep each `.mtl` and the Food kit `Textures` folder next to its models.
Food models use a colour texture atlas; space models use coloured MTL materials.
Try object size 0.6. Use Flip object vertically if needed.
